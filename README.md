# 🍽️ Zomato Restaurant Analytics Dashboard

## 📌 Project Overview

This project is an interactive Power BI dashboard built using the Zomato Restaurant Dataset. The dashboard analyzes restaurant performance across multiple countries and cities, helping users understand customer preferences, restaurant ratings, cuisines, pricing trends, and online delivery availability.

The dataset contains:

- 9,551 Restaurants
- 15 Countries
- 141 Cities

---

## 🎯 Objective

The goal of this project is to transform raw restaurant data into meaningful business insights through interactive visualizations and dashboards.

---

## 📈 Key Insights

- India has the highest number of restaurants in the dataset.
- North Indian cuisine is the most popular cuisine.
- Most restaurants belong to affordable price categories.
- Only a limited percentage of restaurants provide online delivery services.
- Customer engagement is concentrated among a small number of highly voted restaurants.
- Restaurant ratings are generally clustered between 3 and 4.
